# iOS SDK 2.0.1

The native consent screens now use CYBEXO typography and colors, equal accept/reject emphasis, responsive actions and Data Uses, Partners and About navigation. First-banner attribution sits below Manage settings.

This release preserves automatic consent presentation when the app becomes active during initialization, and prevents an open consent screen from saving against changed disclosures. Reopen privacy choices when prompted to review updated settings. Public APIs and saved-choice formats remain compatible with 2.0.0.

App developers should test their own Firebase and optional attribution integrations after updating. Package publication is separate from Google or IAB certification.
